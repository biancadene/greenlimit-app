# GreenLimit

GreenLimit is a mobile-first web app concept for tracking medical cannabis purchase limits, reset windows, and remaining availability in a clearer, more user-friendly way.

## Why I built this

The idea came from a real pain point: checking remaining medical marijuana availability through official systems can feel cumbersome, confusing, and inconvenient. GreenLimit explores a simpler experience that helps patients or caregivers quickly understand:

- how much they have left
- when their limit resets
- how close they are to their current tracked window

## Features

- Track purchases by category:
  - Flower
  - Inhalation
  - Edibles
  - Oral
  - Sublingual
  - Topical
- Rolling 35-day and 70-day tracking windows
- “Available right now” banner
- Dynamic status messaging:
  - Plenty left
  - Getting close
  - Almost at limit
- Mobile-friendly UI
- Local storage support
- Installable PWA setup
- Purchase history with delete option
- Clear-all reset option
